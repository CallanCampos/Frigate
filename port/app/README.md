# port/app/

The program itself, `frigate-black2` or `frigate-white2`: its entry point and options, its window and input, what it
writes for the tests, and the test launcher that opens the field menu's apps for them. It drives the game, which runs
on the platform layer in [../hal](../hal/README.md), and draws what the renderers in [../gfx](../gfx/README.md) make of
the DS's screens. Everything here runs on the program's one thread. The build rules are in
[../CMakeLists.txt](../CMakeLists.txt) (with the launcher's library, `port_launcher`) and
[../cmake/app.cmake](../cmake/app.cmake); the tests are in [../tests/app](../tests/app).

| File | What it does | Part of the game it touches | Tests |
| --- | --- | --- | --- |
| [main.c](main.c) | The entry point: the options and the exit statuses, which `--help` describes, the window, the platform layer, and the game's `main()` on the OS core; the frame hook, which takes the input, presents each frame and paces to the DS's 59.8261 frames a second | The whole game: it starts it and keeps its time | `smoke_reaches_game_main`, `integrate_unknown_option`, `integrate_launch_bad_option`, `app_about` (`--help`), every `replay_*` and `oracle_*` test |
| [present.c](present.c), [present.h](present.h) | The window: both screens stacked in one SDL window, the keyboard, gamepads and mouse as the DS's buttons and touch screen, and PNG screenshots. The window can be resized and is letterboxed: `WINDOW_SCALE` sets its first size, `SDL_SetTextureScaleMode` in `port_present_open` picks the filter (nearest neighbour), `port_present_frame` draws each frame, and `BottomScreenPoint` maps the mouse to the touch screen, which any change of layout must keep in step | The DS's two screens, its buttons and its touch screen | `integrate_screens` (the screenshot); the keyboard and mouse mapping has no test yet |
| [gamepad.c](gamepad.c), [gamepad.h](gamepad.h) | Gamepads as the DS's buttons, by position, with the table of their controls and the pad that drives | The DS's buttons | `app_gamepad_plain`, `app_gamepad_sanitized` |
| [window_icon.c](window_icon.c), [window_icon.h](window_icon.h) | The window's icon on Linux and Windows, Frigate's for the version: the 32 px icon drawn for the window, with the master scaled to 64 px for a display at 200%, from bitmaps the build makes ([../tools/gen_window_icon.c](../tools/gen_window_icon.c), [../assets/branding](../assets/branding/README.md)) | None: the program's look in the taskbar | `app_window_icon_plain`, `app_window_icon_sanitized` |
| [message_log.c](message_log.c), [message_log.h](message_log.h) | An app opened from the Finder: its messages to a log file in `~/Library/Logs/Frigate`, and an alert for a stop the player can act on | None: the program's messages | `app_message_log` (macOS) |
| [replay.c](replay.c), [replay.h](replay.h) | Input replays (`--input`): an input file's buttons, lid and touch on each frame, in place of the window's | The DS's buttons, lid and touch screen, as the game reads them | `replay_start_menu`, `replay_new_game`, `replay_same_save`, the `oracle_*` sequences |
| [run_dir.c](run_dir.c), [run_dir.h](run_dir.h) | The run directory (`--run-dir`) for comparisons with the melonDS oracle: frame rows, screens and memory dumps, and the test launcher's `--launch` in `run.txt` | Any of the game's memory, read for the comparisons | `app_run_dir_plain`, `app_run_dir_sanitized`, `replay_new_game` |
| [symbols.c](symbols.c), [symbols.h](symbols.h) | The program's globals by name, for the run directory's memory dumps, from each host's own symbols ([../hal/host](../hal/host/host.h)) | The game's globals | `app_symbols` |
| [sound_trace.c](sound_trace.c), [sound_trace.h](sound_trace.h) | The sound driver's trace (`--sound-trace`): the host ARM7 sound driver's state after each run of its thread, stamped with the frame and GFL's frame count, in the format pbw-oracle writes for the DS's ([../tools/oracle/sndtrace.h](../tools/oracle/sndtrace.h)), for [sound.py](../tools/oracle/sound.py) to compare | The game's music, sound effects and cries, as the ARM7's driver plays them (read only) | `oracle_sound_opening_hashes`, `oracle_sound_title_hashes`, `oracle_sound_opening`, `oracle_sound_title`; the record's layout `snd_trace_layout` |
| [launcher.c](launcher.c), [launcher.h](launcher.h) | Frigate's test launcher (`--launch`, [ADR 0012](../docs/adr/0012-test-launcher-for-the-field-menus-apps.md)): when a continued game asks for the field, whose code (overlay 36) has no C, it opens the field menu's apps in its place, each at its count of GFL's frames, through the app call's own states (`EventFieldAppCall`), reports each app's result and stops; its exit status says whether the launch finished. It steps aside once the field's process table has C. Test-only, off without the option | The field menu's apps: the party list, the Pokédex, the bag, the trainer card, the summary; CONTINUE's event, where the game's seam in `src/ov035/event_mapchange.c` asks it first | `oracle_launch_field_menus`, `oracle_launch_party_menus`, `launch_summary_standalone`, `launch_touch_then_party`, `launch_unfinished`, `launch_not_offered`, `integrate_launch_never_asked`, `integrate_launcher_off` |
| [launcher_spec.c](launcher_spec.c), [launcher_spec.h](launcher_spec.h) | The launcher's option, `--launch APP[@COUNT],...`, and which apps the save's field menu offers, by the kinds of menu `FieldMenu_GetMenuType` tells apart (read from overlay 36's C, never called) | The field menu's items: no Pokémon, no Pokédex, the Union Room's, the Black Tower's or White Treehollow's without its BAG | `app_launcher_spec_plain`, `app_launcher_spec_sanitized`, `integrate_launch_bad_option`, `launch_not_offered` |
| [macos/](macos) | The macOS app: [make_app.sh](macos/make_app.sh) builds and signs it, [make_icns.sh](macos/make_icns.sh) makes its icon from the master and the small images drawn for 16 and 32 px, [Info.plist.in](macos/Info.plist.in) is its Info.plist, and [bundle_id.cmake](macos/bundle_id.cmake) sets its bundle identifier's prefix (and moves an old build directory's placeholder to Frigate's) | None: the program as a macOS app | `app_make_app`, `app_bundle_id`, `app_package_macos_out` (macOS) |
