# port/app/

The program itself, `frigate-black2` or `frigate-white2`: its entry point and options, its window and input, and what
it writes for the tests. It drives the game, which runs on the platform layer in [../hal](../hal/README.md), and draws
what the renderers in [../gfx](../gfx/README.md) make of the DS's screens. Everything here runs on the program's one
thread. The build rules are in [../CMakeLists.txt](../CMakeLists.txt) and [../cmake/app.cmake](../cmake/app.cmake);
the tests are in [../tests/app](../tests/app).

| File | What it does | Part of the game it touches | Tests |
| --- | --- | --- | --- |
| [main.c](main.c) | The entry point: the options and the exit statuses, which `--help` describes, the window, the platform layer, and the game's `main()` on the OS core; the frame hook, which takes the input, presents each frame, paces to the DS's 59.8261 frames a second and ends each frame of `--frame-times` ([../hal/os/frame_time.h](../hal/os/frame_time.h)) | The whole game: it starts it and keeps its time | `smoke_reaches_game_main`, `integrate_unknown_option`, `app_about` (`--help`), every `replay_*` and `oracle_*` test, the `frame_times_*` routes |
| [present.c](present.c), [present.h](present.h) | The window: both screens stacked in one SDL window, the keyboard, gamepads and mouse as the DS's buttons and touch screen, and PNG screenshots. The window can be resized and is letterboxed: `WINDOW_SCALE` sets its first size, `SDL_SetTextureScaleMode` in `port_present_open` picks the filter (nearest neighbour), `port_present_frame` draws each frame, and `BottomScreenPoint` maps the mouse to the touch screen, which any change of layout must keep in step | The DS's two screens, its buttons and its touch screen | `integrate_screens` (the screenshot); the keyboard and mouse mapping has no test yet |
| [gamepad.c](gamepad.c), [gamepad.h](gamepad.h) | Gamepads as the DS's buttons, by position, with the table of their controls and the pad that drives | The DS's buttons | `app_gamepad_plain`, `app_gamepad_sanitized` |
| [window_icon.c](window_icon.c), [window_icon.h](window_icon.h) | The window's icon on Linux and Windows, Frigate's for the version: the 32 px icon drawn for the window, with the master scaled to 64 px for a display at 200%, from bitmaps the build makes ([../tools/gen_window_icon.c](../tools/gen_window_icon.c), [../assets/branding](../assets/branding/README.md)) | None: the program's look in the taskbar | `app_window_icon_plain`, `app_window_icon_sanitized` |
| [message_log.c](message_log.c), [message_log.h](message_log.h) | An app opened from the Finder: its messages to a log file in `~/Library/Logs/Frigate`, and an alert for a stop the player can act on | None: the program's messages | `app_message_log` (macOS) |
| [record.c](record.c), [record.h](record.h) | Streaming `--record`: exclusive output, effective video-frame states, explicit preboot state and bounded OS seeds, newline commits and I/O rollback | Reproducing field, touch-menu and battle input without replacing game code; same ROM/start save/compatible build required | `app_record_*`, `recording_seed_*`, `pxi_tp_recorded_release`, `replay_recording*` ([ADR 0027](../docs/adr/0027-recorded-input-streams.md)) |
| [replay.c](replay.c), [replay.h](replay.h) | Input replays (`--input`): an input file's buttons, lid and touch on each frame, in place of the window's, and its clock's time, running or pinned | The DS's buttons, lid and touch screen, as the game reads them, and the clock | `replay_start_menu`, `replay_new_game`, `replay_same_save`, the `oracle_*` sequences |
| [run_dir.c](run_dir.c), [run_dir.h](run_dir.h) | The run directory (`--run-dir`) for comparisons with the melonDS oracle: frame rows, screens and memory dumps (`--run-dump`, whose globals `main.c` finds by name through [../hal/host](../hal/host/host.h)'s `port_host_global_address`), and `run.txt` | Any of the game's memory, read for the comparisons | `app_run_dir_plain`, `app_run_dir_sanitized`, `replay_new_game`, `app_symbols` (the lookup of globals) |
| [sound_trace.c](sound_trace.c), [sound_trace.h](sound_trace.h) | The sound driver's trace (`--sound-trace`): the host ARM7 sound driver's state after each run of its thread, stamped with the frame and GFL's frame count, in the format pbw-oracle writes for the DS's ([../tools/oracle/sndtrace.h](../tools/oracle/sndtrace.h)), for [sound.py](../tools/oracle/sound.py) to compare | The game's music, sound effects and cries, as the ARM7's driver plays them (read only) | `oracle_sound_opening_hashes`, `oracle_sound_title_hashes`, `oracle_sound_opening`, `oracle_sound_title`; the record's layout `snd_trace_layout` |
| [macos/](macos) | The macOS app: [make_app.sh](macos/make_app.sh) builds and signs it, from every slice of the program and with the build's architectures and minimum macOS when it sets them (the distribution build's arm64 and x86_64 for macOS 11, [ADR 0015](../docs/adr/0015-universal-macos-app-for-macos-11.md)), [check_app.sh](macos/check_app.sh) prints what an app's or a program's load commands say, slice by slice, and checks its slices, macOS, libraries, each slice's signature and its start, [make_icns.sh](macos/make_icns.sh) makes its icon from the master and the small images drawn for 16 and 32 px, [Info.plist.in](macos/Info.plist.in) is its Info.plist, and [bundle_id.cmake](macos/bundle_id.cmake) sets its bundle identifier's prefix (and moves an old build directory's placeholder to Frigate's) | None: the program as a macOS app, for the Mac that builds it or, from the distribution build, for every Mac with macOS 11 or later (tested so far on macOS 15 and 26); a sanitized build's carries the sanitizer runtime, for testing on this Mac, and `package_macos.sh` puts none in a disk image | `app_make_app`, `app_bundle_id`, `app_package_macos_out`, `app_slices`, `app_universal_slices` (macOS) |
| [windows/](windows/utf8.manifest) | The manifest every Windows program of the build carries, the game's and the tests' ([../CMakeLists.txt](../CMakeLists.txt) embeds it): UTF-8 as the process's code page, so that the arguments, the C library's file calls and SDL's paths agree on a ROM, save folder or run directory named with accents | None: the names of the player's files | `host_files`, `host_utf8_argument` (what they check on Windows) |
